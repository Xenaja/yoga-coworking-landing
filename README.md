# Йога Коворкинг — лендинг

Одностраничный сайт-визитка сети йога-залов на базе библиотек юга Москвы.
Без сборки: статика, ES-модули, деплой на GitHub Pages.

---

## Как посмотреть локально

ES-модули не работают по `file://`. Нужен любой локальный сервер:

```sh
python -m http.server 8080
# открыть http://localhost:8080
```

Черновик открывается в dev-режиме: `<html data-env="dev">`. В этом режиме
элементы с недостающими данными обведены красным пунктиром с подписью
«ЖДЁМ: PENDING-xx». В продакшене атрибут снимается и маркировка исчезает.

## Как менять данные

Все изменяемые значения — в одном месте: блок `<script type="application/json" id="content">`
в начале `index.html`.

```json
{
  "vk_community": "https://vk.ru/club241061217",
  "vk_message":   "https://vk.ru/im?sel=-241061217",
  "telegram":     null,
  "mosru_schedule": null,
  "ip":           null,
  "maps":         null
}
```

`null` означает «данных ещё нет» — соответствующий элемент работает по плану Б
(см. `PENDING.md`). Заглушек в разметке не бывает: либо реальное значение,
либо законченная альтернативная вёрстка.

| Что пришло | Что сделать |
|---|---|
| Ссылка на Telegram | `"telegram": "https://t.me/…"` — вторая кнопка появится рядом с каждой ВК-кнопкой |
| Ссылка на расписание mos.ru | `"mosru_schedule": "https://www.mos.ru/…"` — все упоминания станут ссылками |
| Реквизиты ИП | `"ip": "ИП Фамилия И. О. · ИНН 000000000000 · ОГРНИП 000000000000000"` |
| Другой адрес сообщества ВК | `"vk_message"` в JSON **и** тот же адрес в `href` кнопок (он остаётся фолбэком для браузеров без JS): `sed -i 's|старый|новый|g' index.html` |

Тексты секций, адреса залов и вопросы FAQ — прямо в разметке.
Вопросы FAQ дублируются в JSON-LD `FAQPage` — менять надо в обоих местах.

Цвета, шрифты и кегли — только `css/tokens.css`. Смена акцентного цвета =
одна строка, а не поиск по файлам.

## Публикация

```sh
sh publish.sh https://ваш-домен.ру
```

Скрипт подставит домен в `canonical`, OG, `robots.txt` и `sitemap.xml`,
снимет `data-env="dev"` и `noindex`, прогонит шлюз и, если настроен git remote,
закоммитит и запушит.

Шлюз можно запускать отдельно:

```sh
sh gate.sh
```

Он не пропустит: незакрытые `data-pending`, dev-режим, `noindex`, заглушки,
неподставленный домен и строки со статусом «ждём» в `PENDING.md`.

### После публикации

- Проверить превью ссылки в Telegram и ВК (картинка и заголовок подтягиваются).
- `validator.schema.org` — Organization, 7 × SportsActivityLocation, FAQPage без ошибок.
- Lighthouse mobile: Performance ≥ 90, остальное ≥ 95.
- Добавить сайт в Яндекс.Вебмастер и Google Search Console, отправить sitemap.
- Метрика — когда будет решение по PENDING-06.

## Правила проекта

- Дизайн и вёрстка — по скиллу `landing-quality`; при расхождении с гайдом
  действует `landing-quality/references/CONFLICTS.md`.
- Стили и скрипты — отдельными файлами, инлайновых `style=` и логики в разметке нет.
  Исключение — JSON-LD и блок `#content`, они инлайновые по спецификации.
- Mobile-first, брейкпоинты 640 / 1024 / 1280. Смешивать с `max-width` нельзя.
- Ритм секций A / B / C: соседние не совпадают, один тёмный блок и один брендовый.
- Правки присылать пачкой: одно сообщение = одна итерация = один деплой.
