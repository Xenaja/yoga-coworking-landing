# Йога Коворкинг — Landing

Правила дизайна и вёрстки — скилл landing-quality.
При расхождении с гайдом действует landing-quality/references/CONFLICTS.md.
Спорные решения и отклонения от плана — DECISIONS.md. Недостающие данные — PENDING.md.

## Продукт и аудитория
Сеть доступных йога-залов на базе библиотек юга Москвы (Чертаново, Братеево,
Зябликово, Садовники). Две аудитории: ученики (зал рядом с домом, доступные
цены) и инструкторы (оборудованный зал без аренды, гибкий график).
Сайт — информационная визитка ИП. Оплат и форм с персональными данными НЕТ.

## Цель лендинга
Одно целевое действие, один глагол: **написать**. Два канала:
заливная кнопка «Написать в ВК» (vk.ru/im?sel=-241061217, сообщения включены)
и вторичная обводкой «Написать в Telegram» (t.me/natalimorozova7sky).
Заливная в экране одна — Telegram всегда вторичный.
Расписание mos.ru — вторичное текстовое упоминание (PENDING-01).

## Арт-направление
Журнальное (Editorial), рестайлинг 2026-09-02 по `design_handoff_landing_restyle/`
(режим Б — макет-референс, детали в DECISIONS.md). Крупная антиква, курсивный
акцент в заголовках, hero — полноэкранный фулл-блид кадр с тёмными вуалями.

Сигнатурный приём — рейл секции: номер раздела / линия / имя раздела
(`01 / 08 · Что это`), плюс номера пунктов Literata рядом со списками.
Иконок на странице нет.

Шрифты: Literata (заголовки, есть курсив-акцент) + Golos Text (текст).
Inter, Roboto, Montserrat запрещены.

## Стиль
Ощущение: доступный, спокойный, дружелюбный, чуть более редакционный после рестайлинга.
Фон светлый тёплый #FAF8F5, текст #241F2B / #57505C.
Акцент #8A6AA4, ховер #5C3B6E, тёмный блок #341831 (он же hero-фон и футер),
брендовый блок #4A2450. Палитра снята с логотипа: сливовый тон, не сине-фиолетовый.
Все значения — в css/tokens.css, менять только там.
Запрещено: эзотерические штампы, «лотос на закате», градиенты-переливы,
таймеры, glassmorphism, emoji вместо иконок.

## Технический стек
- Статика без сборки. Стили и скрипты — **отдельными файлами**
  (правило заказчика сильнее «одного HTML-файла» из гайда, см. DECISIONS.md):
  css/tokens → base → components → sections; js/main + модули content, nav, reveal, faq.
- Инлайн только у JSON-LD и блока #content — по спецификации. Инлайновых `style=`
  в разметке нет вообще, включая одноразовые отступы — те живут в CSS контекстными
  селекторами (`#about .grid`, `.rail + h2` и т.п.).
- ES-модули: локальный просмотр требует сервера (`python -m http.server`).
- Mobile-first, брейкпоинты 640 / 1024 / 1280. Смешивать с max-width нельзя.
- Фото: photos/hero (+ hero-800 под srcset), photos/practice, photos/halls —
  WebP + JPG, все < 300 КБ.
- Sticky CTA на мобиле: ВК заливкой + Telegram обводкой, body имеет padding-bottom.
- FAQ — управляемый аккордеон (js/faq.js): один открытый вопрос, первый открыт
  по умолчанию, высота анимируется по scrollHeight. Не нативные `<details>` —
  так не получить одновременно анимацию и «раскрыт только один».

## Решения, которые уже приняты
- Оплаты на сайте нет; записи и расписание живут на mos.ru (2026-09-02).

  на бумажной плашке, из него же фавиконы. Бренд пишем «Йога Коворкинг».
- Публикация с выдуманными фактами запрещена: шлюз gate.sh обязателен.
