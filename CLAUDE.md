# Йога Коворкинг — Landing

Правила дизайна и вёрстки — скилл landing-quality.
При расхождении с гайдом действует landing-quality/references/CONFLICTS.md.
Спорные решения и отклонения от плана — DECISIONS.md. Недостающие данные — PENDING.md.

## Продукт и аудитория
Сеть доступных йога-залов на базе библиотек юга Москвы (Чертаново, Братеево,
Зябликово, Садовники). Две аудитории: ученики (зал рядом с домом, доступные
цены) и инструкторы (оборудованный зал без аренды, гибкий график).
Сайт — информационная визитка ИП. Оплат и форм с персональными данными НЕТ.

## Цель лендинга
Одно целевое действие, один глагол: **написать**.
Кнопка ведёт в сообщения сообщества ВК (vk.ru/im?sel=-241061217).
Telegram появится второй, вторичной кнопкой, когда придёт ссылка (PENDING-10).
Расписание mos.ru — вторичное текстовое упоминание (PENDING-01).

## Арт-направление
Журнальное (Editorial): крупная антиква, линейки-разделители, воздух,
почти без заливок. Интонация «библиотечная», без эзотерических штампов.

Сигнатурный приём — **библиотечный шифр**: моно-ярлык в тонкой рамке.
Живёт в лейблах секций (01 / 08), номерах залов (№ 143) и номерах шагов.
Больше нигде. Иконок на странице нет.

Шрифты: PT Serif (заголовки) + Onest (текст) + JetBrains Mono (только лейблы
и цифры). Inter, Roboto, Montserrat запрещены.

## Стиль
Ощущение: доступный, спокойный, дружелюбный.
Фон светлый тёплый #FAF8F5, текст #2B2733 / #4A4553.
Акцент #7C5CBF, ховер и ссылки #5F449B, брендовый блок #4C3580.
Все значения — в css/tokens.css, менять только там.
Запрещено: тёмный фон как основной, эзотерические штампы, «лотос на закате»,
градиенты-переливы, таймеры, glassmorphism, emoji вместо иконок.

## Технический стек
- Статика без сборки. Стили и скрипты — **отдельными файлами**
  (правило заказчика сильнее «одного HTML-файла» из гайда, см. DECISIONS.md):
  css/tokens → base → components → sections; js/main + модули content, nav, reveal.
- Инлайн только у JSON-LD и блока #content — по спецификации.
- ES-модули: локальный просмотр требует сервера (`python -m http.server`).
- Mobile-first, брейкпоинты 640 / 1024 / 1280. Смешивать с max-width нельзя.
- Фото: photos/hero, photos/practice, photos/halls — WebP + JPG, все < 300 КБ.
- Sticky CTA на мобиле: одна кнопка «Написать в ВК», body имеет padding-bottom.

## Структура (9 секций), ритм A B A C B A B A C
1 Hero (A) → 2 Что это (B) → 3 Ученикам (A) → 4 Инструкторам (C, брендовый) →
5 Требования (B) → 6 Наши залы (A) → 7 Как начать (B) → 8 Вопросы (A) →
9 Контакты и футер (C, тёмный).
Ровно один тёмный и один брендовый полноширинный блок — больше не добавлять.

## SEO / AEO
- H1 «Йога-коворкинг в вашем районе»; первый абзац секции «Что это» —
  прямой ответ «что / для кого / где» с районами словами.
- JSON-LD: Organization + SportsActivityLocation ×7 + FAQPage. Event не нужен.
- geo и openingHours не заполняем — выдуманные данные запрещены.
- Черновик под noindex, домен подставляется токеном {{SITE_URL}}.

## Деплой
GitHub Pages. `sh publish.sh https://домен` — подстановка домена, снятие
чернового режима, шлюз, коммит и пуш. `sh gate.sh` — только проверка.

## Решения, которые уже приняты
- Оплаты на сайте нет; записи и расписание живут на mos.ru (2026-09-02).
- Требования к инструкторам — отдельная секция-фильтр выше FAQ.
- Карточки залов — каталожный список без фото; фото отдельной лентой
  с нейтральной подписью (нет соответствия фото ↔ зал, PENDING-12).
- Логотип: кириллический знак в шапке (локап знак + название), в футере
  на бумажной плашке, из него же фавиконы. Бренд пишем «Йога Коворкинг».
- Публикация с выдуманными фактами запрещена: шлюз gate.sh обязателен.
